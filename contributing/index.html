    Welcome, Contributor

    • Dev Setup

      Install dependencies, run the app locally in dev mode, and understand the project's file structure.

    • Adding a Game

      Step-by-step guide for adding a new game server type--config file, icon, registry entry, process category, and quick actions.

      How Electron IPC works in RSM, the three communication patterns, and the full current channel list.

      IPC Reference

    • UI Guide

      How RSM's vanilla-JS renderer is structured, the CSS custom properties for theming, and the runtime server state object.

      UI Guide

    • REST API

      How api-server.js is architected, how to add new endpoints, and how to add player-count or command support for a new game type.
